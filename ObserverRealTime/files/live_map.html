Test clock override
For a bench whose transmitter has no RTC, GNSS or NTP. It replaces the reference time used for E-LINK-04 and E-FRESH-01 only.

It does not correct the aircraft. It makes this observer agree with a clock known to be wrong, so any run with it set is a bench exercise and not evidence. Stale/drop timing always stays on the real clock.

This page is a monitoring view, not the conformance report. It judges each message with only what has arrived so far, so it can disagree with a full run of observer.py over the finished capture file. That batch run remains the authoritative result.
